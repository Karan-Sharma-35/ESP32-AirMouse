# Esp32 AirMouse Project

### Equipment:
- ESP32 microcontroller
- Joystick Shield

### Software:
- Arduino IDE

### Description:
With the use of the the bluetooth and wifi capabilities of the ESP32, I plan to use a regular joystick shield to make a working AirMouse that can be used wherever I go. The AirMouse should be able to also handle mouse button 4 and mouse button 5 setup that a lot of modern mice have. I have also added functionality to allow the user to change the AirMouse's sensitivity.

### Progress:
Hardware testing is completed, there will be a demo video for the prototype. Currently designing the PCB for the board to shed reliability of the breadboard and reduce space it consumes to match the housing, as shown in the STL files.
